# 검증 기록 (2026-10-10)

## 환경
- **실제 운영 DB(ovot_db)에는 접속하지 않았습니다.** 별도 PostgreSQL 16 테스트 DB 를 만들었습니다.
- 기본 테이블 구조는 `models.py`와 migrations 주석을 근거로 재구성했습니다(`tools/test-db/000_base_schema.sql`). 그 위에 OVOT-Backend `migrations/001~006` 을 그대로 실행했습니다.
- 데이터는 CASE 대본 1~5 기반 샘플입니다(`src/demo/scenario.json` → `tools/test-db/seed.py`). README 에 적힌 구형 코드 `WORK_PRIORITY_CHANGED` 1건도 재현했습니다.
- OVOT-Backend 코드는 **수정 없이** 실행했습니다(uvicorn :8000). 관리자 웹은 Vite 개발 서버(:5173)에서 Chromium 으로 자동 검증했습니다.
