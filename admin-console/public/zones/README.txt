구역 사진 넣는 곳

- 파일 이름은 zone-map.json 의 image 값과 같아야 합니다. 기본값: ZONE-A.jpg, ZONE-B.jpg, ZONE-C.jpg, ZONE-D.jpg, ZONE-E.jpg
- 팀이 직접 찍었거나 사용 허락을 받은 사진만 넣어 주세요 (출처 불명 사진·생성형 이미지 사용 금지).
- 가로 사진 권장 (약 1200×900 px 이상, 500KB 이하 JPG).
- 사진이 없으면 화면에 '사진 등록 필요' 안내가 표시됩니다.
- 잘리는 위치는 zone-map.json 의 imagePosition 으로 조절합니다 (예: "50% 30%" = 가운데, 위쪽 30% 지점 기준).
